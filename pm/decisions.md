# Decisions — Simon

*Append-only, dated record of product, technical, and governance decisions.*

- **2026-11-21 · Project Name & Core Thesis**: Named the project **Simon** — a multimodal talent-scouting and live-showcase production system starting with emerging vocalists (*First Listen NYC*), designed as a reusable scouting/critic engine across scenes and modalities.
- **2026-11-21 · Hackathon Track Selection**: Prioritize **Best Use of Managed Agents ($5,000)** at the Gemini 4 NYC Hackathon; skip forced Shopify/merch/dropshipping integration because it does not naturally fit the scouting product.
- **2026-11-21 · Critic / Validator Multi-Agent Pattern**: Use independent specialist Managed Agents ("critics/validators" for musical performance vs. practical booking fit) followed by a Producer synthesis agent that highlights disagreements rather than averaging scores.
- **2026-11-21 · Life OS Repo Knowledge Model**: Adopted the Life OS-inspired repo structure (`PROJECT.md`, `RESOURCES.md`, `pm/`, `notes/managed-agents/`, `agents/`, `simon/`, `data/`, `examples/`, `local/`, `ideas/`, `tests/`, `.agents/`) with setup-stage filing confirmation and a background Project Manager (Steward) subagent.
- **2026-11-21 · Shared Partner Sync (`RESOURCES.md` + `origin/main`)**: Maintain a root `RESOURCES.md` and commit/push updates to `origin/main` (`jontumalle/simon`) so both teammates' agents can pull and self-install required tools.
- **2026-11-21 · Zero-Repercussion `main` Doc Pushing & Cross-Window Steward**: All documentation and knowledge-model files (`*.md`, `pm/`, `notes/`, `ideas/`, `data/`, `agents/`, `.agents/`) push straight to `origin/main` with zero repercussions via `sync_main.py` (`pull --rebase --autostash`), enforced by `Stop`/`SessionStart` hooks and a background `Project Manager (Steward)` subagent in every chat window.
- **2026-11-21 · Repo-Scoped PreToolUse Toolchain Auto-Approval**: Added `.agents/scripts/auto_approve_toolchain.py` wired under `PreToolUse` (`matcher: "run_command"`) in `.agents/hooks.json` so both teammates' agents automatically approve safe Simon toolchain commands (`RESOURCES.md`) without manual prompts while keeping destructive, token-exfiltrating, or untrusted commands gated by default policy.
- **2026-11-21 · Dual-Track Sync Skill (Docs vs. Code) & Steward Auto-Approval**: Split `.agents/skills/main-sync/SKILL.md` and `.agents/scripts/sync_main.py` into **Track A (`--docs-only`)** — end-to-end auto-approved doc file creation/edits (`PreToolUse`) and direct `origin/main` sync that preserves dirty `simon/` or `tests/` code — and **Track B (`--code --paths <files...>`)** — mandatory `unittest` + `python -m simon` smoke + `ruff check --select E9,F` verification with explicit slice staging (and optional `--branch feat/<slug>` + PR), keeping `--skip-verify` and unscoped `--all` gated by manual review.
- **2026-11-21 · Non-Binary Process Observer & System Improvement Loop (`pm/process/`)**: Created `.agents/skills/process-observer/` (with `inspect_sessions.py` transcript telemetry) and `pm/process/` (`observations.md` + `synthesis.md`) so a dedicated System Improver agent can continuously evolve hooks, skills, and multi-window workflows along calibrated tradeoff spectrums rather than binary pass/fail or on/off choices.
- **2026-11-21 · Plain-English Skill, Global Rule & Adaptive Execution Gate**: Added `.agents/skills/plain-english/SKILL.md` (`0ef97f2`) and user-level global rule `~/.gemini/config/rules/plain-english.md` (`trigger: always_on`) enforcing STE-100 + William Zinsser clarity on every turn, paired with an **Adaptive Exploration vs. Execution Gate** (align first when intent carries ambiguity or trade-offs; execute directly on explicit commands and background subagents so autonomous workers never stall).
- **2026-11-21 · Public YouTube + Direct `gemini-4-hydrogen` Video Input over SoundCloud API**: Standardized MVP scouting discovery and listening on zero-signup public YouTube URLs (search + oEmbed verification + performer attribution flags in `simon/youtube.py`) passed directly into `gemini-4-hydrogen`, because Gemini natively ingests public YouTube videos with timestamp grounding whereas SoundCloud API terms prohibit feeding API tracks into AI models.
- **2026-11-21 · 3-Unit Pipeline Contracts, Team Split & SQLite Play-First Store**: Aligned team architecture so Kevin builds the minimal Managed Agent factory, CI checks, and GitHub Actions deployment pipeline while Jonathan ships the scouting & human-verification MVP across 3 contract-defined units (`data/mvp_contracts.json`: 1. Video Discovery & Info Extraction, 2. Decision/Synthesis + Thin-Evidence Second-Take Loop, 3. Normalized 5-table SQLite Evidence Store `local/simon.db` + Play-First Scouting Studio UI `python3 -m simon serve`), capping shortlists at `<= 3` vocalists and retaining `source_url` + timestamped `play_url` on every observation.
