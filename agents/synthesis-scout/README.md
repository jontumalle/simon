# `simon-synthesis-scout`

Curated Gemini Managed Agent (`antigravity-preview-09-2026` · `gemini-4-carbon`) that compares evaluated YouTube clip evidence against the taste brief, writes brief-specific `ArtistAssessment` records, and produces a **<= 3 singer Listening Shortlist** with clickable `play_first_url` timestamps, fit rationale, next-listen guidance, and single-clip / attribution flags.

## Test Commands
```sh
python3 -m simon scout
python3 -m simon serve --port 8765
```
